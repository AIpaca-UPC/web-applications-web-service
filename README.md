# Rumbo — RESTful Web Services

Repositorio de los **RESTful Web Services** de Rumbo para el curso **1ASI0730 Aplicaciones Web**.

El Final Project Statement exige que el equipo declare el URL de este repositorio en **Source Code Management** desde AV1. La implementación del Web Service no forma parte del incremento exigido en AV1, por lo que no se agrega estructura de código innecesaria en esta entrega.

Tecnologías definidas para el curso: **ASP.NET Core, Entity Framework Core, C# y OpenAPI/Swagger**.

Cuando empiece su implementación, este mismo repositorio deberá contener tanto el proyecto del Web Service como sus pruebas unitarias y de integración/aceptación.
